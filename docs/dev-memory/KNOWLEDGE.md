# 可复用经验

保存可跨项目复用的方法、踩坑经验和待验证想法，注明适用边界与出处。没有新发现时保持不变。

## K-001 · 视觉对比度须检查最终 CSS 级联
- 来源：2026-10-21 卡牌与获胜提示调整。共享 SVG 配色会同步影响手牌、二维和三维材质，但手牌等待状态还会受到 cinematic.css 与 clarity.css 的不同去色和亮度滤镜影响。
- WebGL 获胜标签的旧选择器包含 body 状态、has-webgl 和 winner，优先级高于普通获胜样式；只改变前景色会留下旧深底，反而变得难读。最终同时覆盖二维和 WebGL 标签的背景、文字及边框。
- 可复用做法：按真实 disabled、WebGL 和手机状态拍截图，检查实际级联，而不是只看配色常量或某一层样式。获胜标记同时使用颜色、边框与「获胜」文字，不只依赖色相。
- 2026-10-21 用户进一步明确等待时也要完整牌面亮度：禁用操作与视觉可读性应分开，使用可出牌金边表示权限。最终同时去掉基础卡牌、手牌及禁用悬停的压暗滤镜；只改桌面材质颜色，避免全画布滤镜连牌面一起变暗。
